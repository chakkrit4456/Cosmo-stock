# CosmoStock — คู่มือหน้าจอ (UI)

ภาพหน้าจอทุกหน้าของเว็บแอป **CosmoStock** (ระบบจัดการคลังเครื่องสำอาง) บน 5 อุปกรณ์ พร้อมคำอธิบายว่าแต่ละหน้าคืออะไร ปุ่มทำอะไรได้บ้าง และวิธีใช้งานคร่าว ๆ

## โครงสร้างโฟลเดอร์

| โฟลเดอร์ | อุปกรณ์ | ขนาดจอที่ใช้แคป |
|---|---|---|
| `1-Desktop` | คอมพิวเตอร์ | 1440 × 900 |
| `2-iPad` | iPad | 820 × 1180 |
| `3-AndroidTablet` | แท็บเล็ต Android | 800 × 1280 |
| `4-iPhone` | iPhone | 390 × 844 |
| `5-Android` | มือถือ Android | 412 × 915 |

ทุกโฟลเดอร์มีไฟล์ชื่อเดียวกัน เช่น `03-dashboard.png` จึงเปิดเทียบข้ามอุปกรณ์ได้ทันที (ภาพเป็นแบบเต็มหน้า ยกเว้นหน้าต่างป๊อปอัปที่แคปเฉพาะหน้าจอ)

**หมายเหตุ:** ข้อมูลในภาพเป็น *ข้อมูลตัวอย่าง* (ร้าน Rose Beauty) ที่ระบบสร้างให้ตอนรัน `npm run reset` ไม่ใช่ข้อมูลจริงในฐานข้อมูลของคุณ ภาพทั้งหมดล็อกอินด้วยบัญชีเจ้าของร้าน ยกเว้นหน้า 17 ที่ใช้บัญชีผู้ดูแลระบบ

## หน้าตาของเมนูในแต่ละอุปกรณ์

| อุปกรณ์ | การนำทาง |
|---|---|
| Desktop | แถบเมนูด้านซ้ายแบบเต็ม (ไอคอน + ชื่อเมนู) มีช่องค้นหาและปุ่มลัดอยู่บนหัวหน้า |
| iPad / Android Tablet | แถบเมนูด้านซ้ายแบบย่อ (ไอคอนอย่างเดียว) และแถบบนมีปุ่มสแกน กระดิ่ง และรูปโปรไฟล์ |
| iPhone / Android | แถบบนมีปุ่มสแกน กระดิ่ง โปรไฟล์ และเมนูล่าง 5 ปุ่ม: หน้าแรก · สินค้า · รับเข้า · จ่ายออก · เพิ่มเติม (เมนูอื่น ๆ อยู่ในหน้า "เพิ่มเติม") |

ปุ่มและเมนูที่ผู้ใช้ไม่มีสิทธิ์จะถูกซ่อนอัตโนมัติ (เจ้าของร้าน / ผู้จัดการ / พนักงานคลัง / ดูอย่างเดียว) รายการข้างล่างเป็นมุมมองของ **เจ้าของร้าน** ซึ่งเห็นครบทุกปุ่ม

## 10. ปรับยอดสต็อก — `10-stock-adjust.png`
**คืออะไร:** 3 หน้านี้ใช้โครงเดียวกัน มีแท็บ *รับเข้า / จ่าย/เบิก / ปรับยอด* ด้านบนเพื่อสลับ

| ปุ่ม / ส่วน | ทำอะไร |
|---|---|
| ช่องค้นหาสินค้า | พิมพ์ชื่อ/SKU แล้วเลือกจากรายการที่ขึ้นมา หรือยิงบาร์โค้ด |
| ปุ่มสแกน | สแกนบาร์โค้ด/QR ด้วยกล้อง |
| การ์ดสินค้าที่เลือก + ปุ่ม X | แสดงคงเหลือปัจจุบัน กด X เพื่อเปลี่ยนสินค้า |
| หน่วยที่ทำรายการ | เลือกชิ้น / แพ็ค / ลัง (ระบบแปลงเป็นชิ้นให้) |
| จำนวน (− / +) | ใส่จำนวนที่รับเข้า/จ่ายออก |
| ล็อต / วันหมดอายุ (รับเข้าสินค้าที่ติดตามล็อต) | ระบุล็อตและวันหมดอายุ |
| ผู้จำหน่าย / หมายเหตุ + ปุ่มลัดข้อความ | เช่น "บจก. บิวตี้ซัพพลาย", "ขายหน้าร้าน" |
| "หลังบันทึก  45 → 46" | พรีวิวยอดคงเหลือก่อนกดบันทึก |
| บันทึกรับเข้า / บันทึกจ่ายออก / บันทึกปรับยอด | บันทึกรายการ ออกเลขเอกสารอัตโนมัติ (RCV / ISS / ADJ) |

**วิธีใช้:**
1. *รับเข้า* — ของเข้าคลัง เลือกสินค้า → ใส่จำนวน (+ล็อต/วันหมดอายุ) → บันทึก
2. *จ่าย/เบิก* — ของออก (ขาย/เบิกไปสาขาอื่น) จ่ายเกินคงเหลือไม่ได้ ระบบตัดล็อตที่หมดอายุก่อนให้
3. *ปรับยอด* — ใส่ยอดที่นับจริง ระบบคำนวณส่วนต่างและบันทึกเหตุผล (เฉพาะเจ้าของ/ผู้จัดการ)

## 14. ผู้ใช้และสิทธิ์ — `14-users.png`, `14b-users-invite-dialog.png`
**คืออะไร:** (เฉพาะเจ้าของร้าน) จัดการคนที่เข้าถึงร้านและบทบาท

| ปุ่ม | ทำอะไร |
|---|---|
| เชิญผู้ใช้ | เปิดหน้าต่างเพิ่มคนเข้าร้าน: กรอกอีเมล ชื่อ-นามสกุล เลือกบทบาท และรหัสผ่านเริ่มต้น (ปุ่ม *สุ่มใหม่* สร้างรหัสให้) แล้วกด *เพิ่มเข้าร้าน* — ถ้าอีเมลนั้นมีบัญชีอยู่แล้วจะใช้รหัสเดิมของเขา |
| เมนูเลือกบทบาทในแถวผู้ใช้ | เปลี่ยนบทบาทของผู้ใช้คนนั้น (เจ้าของร้าน / ผู้จัดการ / พนักงานคลัง / ดูอย่างเดียว หรือบทบาทที่สร้างเอง) |
| กำหนดสาขา | เลือกสาขาที่ผู้ใช้คนนั้นเข้าได้ |
| ไอคอนกุญแจ | ตั้งรหัสผ่านใหม่ให้ผู้ใช้ที่ลืมรหัส |
| ไอคอนถังขยะ | นำผู้ใช้ออกจากสาขานี้ |
| ตารางบทบาทและสิทธิ์ (ช่องติ๊ก) | ปรับว่าแต่ละบทบาททำอะไรได้บ้าง เช่น เพิ่ม/แก้ไขสินค้า ลบสินค้า รับเข้า/จ่ายออก ปรับยอด ดูรายงาน |
| เพิ่มบทบาท / ไอคอนดินสอ / ถังขยะ ท้ายคอลัมน์บทบาท | สร้าง แก้ชื่อ หรือลบบทบาทของร้าน |

**วิธีใช้:** กด *เชิญผู้ใช้* → กรอกข้อมูล → เลือกบทบาท → ส่งรหัสเริ่มต้นให้พนักงาน แล้วให้เขาเปลี่ยนรหัสเองที่หน้าตั้งค่า

## 18. หน้าต่างสแกน — `18-scan-dialog.png`
**คืออะไร:** เปิดจากปุ่มสแกนที่ใดก็ได้ ใช้กล้องมือถือสแกน Barcode/QR เพื่อเปิดสินค้าหรือเลือกสินค้าในหน้ารับเข้า/จ่ายออก

| ส่วน | ทำอะไร |
|---|---|
| ภาพจากกล้อง | ยกกล้องส่องบาร์โค้ด/QR |

> ภาพนี้เป็นสถานะที่ **กล้องไม่เปิด** (ข้อความ "เปิดกล้องไม่ได้ … พิมพ์รหัสด้านล่างแทนได้") เพราะเครื่องที่ใช้แคปไม่มีกล้อง/อินเทอร์เน็ต ในการใช้งานจริงกล้องจะเปิดเมื่อเข้าผ่าน HTTPS หรือ localhost

## ขั้นตอนใช้งานคร่าว ๆ (ตัวอย่าง 1 วันของร้าน)
1. **เข้าสู่ระบบ** → ดู **Dashboard** ว่ามีแจ้งเตือนอะไร
2. ของมาส่ง → **รับเข้า** (สแกน/ค้นสินค้า → จำนวน → ล็อต/วันหมดอายุ → บันทึก)
3. ขายหรือเบิกของ → **จ่าย/เบิก**
4. นับสต็อกสิ้นเดือนแล้วไม่ตรง → **ปรับยอด** พร้อมหมายเหตุ
5. ตรวจ **แจ้งเตือน** แล้วสั่งซื้อของที่ใกล้หมด/ขายของที่ใกล้หมดอายุก่อน
6. สิ้นเดือนดู **รายงาน** แล้วส่งออก PDF/Excel
7. เจ้าของร้านเพิ่มพนักงานที่ **ผู้ใช้และสิทธิ์** แล้วกด **ออกจากระบบ** เมื่อเลิกใช้งาน
