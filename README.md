# CosmoStock — ระบบจัดการคลังเครื่องสำอาง

จัดการคลังง่าย สต็อกแม่น ธุรกิจเติบโต

## วิธีรัน

ต้องมี Node.js 22.13 ขึ้นไป (ไม่ต้อง `npm install` เพราะไม่มี dependency)

```bash
npm start          # เปิดเซิร์ฟเวอร์ที่ http://localhost:3000
npm run reset      # ลบฐานข้อมูลแล้วสร้างข้อมูลตัวอย่างใหม่
```

- เปิดจากมือถือ/แท็บเล็ตที่ต่อ Wi-Fi เดียวกันได้ที่ `http://<IP เครื่อง>:3000` (เซิร์ฟเวอร์จะพิมพ์ URL ให้ตอนเริ่ม)
- การสแกนบาร์โค้ดด้วยกล้องต้องเปิดผ่าน HTTPS หรือ localhost ถ้าไม่ได้จะพิมพ์รหัสเองได้
- ข้อมูลเก็บที่ `data/cosmostock.db` (SQLite)
- เปลี่ยนบัญชีแอดมินเริ่มต้นได้ด้วย env `ADMIN_EMAIL`, `ADMIN_PASSWORD` (มีผลตอนสร้างฐานข้อมูลครั้งแรก)
