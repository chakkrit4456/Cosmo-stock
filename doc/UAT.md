# แผนและแบบบันทึกการทดสอบการยอมรับของผู้ใช้ (UAT) — CosmoStock

> สร้างอัตโนมัติจากสคริปต์เดียวกับไฟล์ Word — แก้กรณีทดสอบแล้วสร้างใหม่ทั้งสองไฟล์

- **วัตถุประสงค์:** ให้ผู้ใช้งานจริง (เจ้าของร้าน ผู้จัดการ พนักงาน ผู้ตรวจสอบ และผู้ดูแลระบบ) ทดสอบว่า CosmoStock ทำงานตรงกับความต้องการก่อนเริ่มใช้กับข้อมูลจริง
- **ระบบที่ทดสอบ:** https://cosmostock.onrender.com (Render + Supabase PostgreSQL) — ใช้ข้อมูลตัวอย่างร้าน Rose Beauty
- **ก่อนเริ่ม (Entry):** Unit test และ smoke test ผ่านทั้งหมด / เว็บเปิดได้ / ผู้ทดสอบได้รับบัญชีตามบทบาท
- **เกณฑ์ผ่าน (Exit):** ทุกข้อในหมวด A, C, D, F ผ่าน / ไม่มีข้อบกพร่องระดับวิกฤตหรือสูงค้างอยู่ / ผู้มีอำนาจลงนามรับรอง
- **หลังจบ UAT:** ลบข้อมูลทดสอบและบัญชีตัวอย่าง เปลี่ยนรหัสผ่านทุกบัญชี แล้วจึงเริ่มใช้ข้อมูลจริง
