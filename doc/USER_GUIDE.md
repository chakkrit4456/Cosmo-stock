## 1. เริ่มต้นใช้งาน

### 1.1 เปิดเว็บ
- **บนเครื่องที่รันเซิร์ฟเวอร์**: เปิด `http://localhost:3000`
- **มือถือ/แท็บเล็ตที่ต่อ Wi-Fi เดียวกัน**: เปิด `http://<IP ของเครื่องเซิร์ฟเวอร์>:3000` (ตอนเริ่มเซิร์ฟเวอร์จะพิมพ์ URL ให้ในหน้าต่าง Terminal)
- **ถ้าขึ้นระบบออนไลน์แล้ว**: ใช้ URL ที่ผู้ดูแลระบบให้มา (ควรขึ้นต้นด้วย `https://`)

### 1.2 อุปกรณ์ที่รองรับ
iPhone, Android, iPad, Android Tablet และคอมพิวเตอร์ (Chrome, Edge, Safari, Firefox รุ่นล่าสุด) หน้าจอจะปรับตามขนาดเครื่องเอง

### 1.3 ติดตั้งเป็นแอปบนหน้าจอโฮม (ไม่บังคับ)
- **iPhone/iPad (Safari)**: กดปุ่มแชร์ แล้วเลือก “เพิ่มไปยังหน้าจอโฮม”
- **Android (Chrome)**: กดเมนู ⋮ แล้วเลือก “เพิ่มลงในหน้าจอหลัก” หรือ “ติดตั้งแอป”

จากนั้นจะมีไอคอน CosmoStock บนหน้าจอและเปิดแบบเต็มจอเหมือนแอปทั่วไป (ยังต้องต่ออินเทอร์เน็ตหรือเครือข่ายที่เข้าถึงเซิร์ฟเวอร์ได้)

## 3. เข้าสู่ระบบ เปิดร้านใหม่ และออกจากระบบ

### 3.1 เข้าสู่ระบบ
1. เปิดเว็บ ระบบจะพาไปหน้า **เข้าสู่ระบบ**
2. กรอก **อีเมล** และ **รหัสผ่าน** (กดรูปตาเพื่อแสดง/ซ่อนรหัสผ่าน)
3. **จดจำฉัน** (ติ๊กไว้เป็นค่าเริ่มต้น): จำการเข้าสู่ระบบไว้ 30 วัน ถ้าไม่ติ๊กจะหลุดเมื่อปิดเบราว์เซอร์ หรือครบ 12 ชั่วโมง
4. กด **เข้าสู่ระบบ**

> ถ้ากรอกผิด 8 ครั้งภายใน 10 นาที ระบบจะล็อกการเข้าสู่ระบบของอีเมลนั้น (จากเครื่องนั้น) ไว้ 10 นาที

### 3.2 เปิดร้านใหม่
ระบบ **ไม่มีหน้าสมัครสมาชิก** บุคคลทั่วไปสร้างบัญชีหรือร้านเองไม่ได้ ร้านใหม่สร้างได้ 2 ทาง
1. **ผู้ดูแลระบบ** → **สร้างร้านใหม่** กรอกชื่อร้าน ชื่อสาขาแรก (เว้นว่าง = `สาขาหลัก`) และอีเมลเจ้าของร้าน ระบบจะสร้างบัญชีเจ้าของร้านให้ (หรือใช้บัญชีเดิมถ้ามีอีเมลนี้แล้ว)
2. **เจ้าของร้านที่มีบัญชีอยู่แล้ว** → **ตั้งค่า** → การ์ด **ร้านและสาขาของฉัน** → **สร้างร้านใหม่** (แยกข้อมูลจากร้านเดิมทั้งหมด)

พนักงานได้บัญชีจากการที่เจ้าของร้านเชิญที่เมนู **ผู้ใช้และสิทธิ์**

### 3.3 ลืมรหัสผ่าน
หน้าเข้าสู่ระบบไม่มีปุ่มลืมรหัสผ่าน และระบบไม่ส่งอีเมลรีเซ็ต ให้ทำดังนี้
- **พนักงาน/ผู้จัดการ/ดูอย่างเดียว**: แจ้งเจ้าของร้านให้ตั้งรหัสผ่านใหม่ให้ (หัวข้อ 14.4)
- **เจ้าของร้าน**: แจ้งผู้ดูแลระบบให้ตั้งรหัสผ่านใหม่ที่หน้า **ผู้ดูแลระบบ** → ปุ่มกุญแจที่แถวผู้ใช้

### 3.4 บัญชีที่ยังไม่อยู่ในร้านใด
ถ้าถูกนำออกจากร้านทุกร้าน หลังเข้าสู่ระบบจะเห็นหน้า “ยังไม่มีร้าน” ให้เลือกระหว่างรอเจ้าของร้านเชิญเข้าร้านอีกครั้ง หรือสร้างร้านใหม่ของตัวเอง

### 3.5 ออกจากระบบ
- **มือถือ**: แท็บ **เพิ่มเติม** แล้วกด **ออกจากระบบ** ด้านล่าง
- **แท็บเล็ต/คอมพิวเตอร์**: ไอคอนประตูข้างชื่อผู้ใช้มุมซ้ายล่าง หรือปุ่ม **ออกจากระบบ** ในหน้าตั้งค่า

## 4. หน้าจอและการนำทาง

| ขนาดจอ | รูปแบบเมนู |
| --- | --- |
| คอมพิวเตอร์ (กว้าง ≥ 1100px) | เมนูด้านซ้ายแบบเต็ม: โลโก้, ปุ่มเลือกร้าน, เมนูทั้งหมด, ชื่อผู้ใช้ และปุ่มออกจากระบบ |
| แท็บเล็ต (768–1099px) | เมนูด้านซ้ายแบบไอคอน + แถบบนที่มีปุ่มเลือกร้าน, ปุ่มสแกน, กระดิ่งแจ้งเตือน, รูปผู้ใช้ |
| มือถือ (< 768px) | แถบบน + แถบเมนูล่าง 5 ปุ่ม |

**แถบเมนูล่างบนมือถือ**
- ผู้ที่รับเข้า/จ่ายออกได้ (เจ้าของร้าน ผู้จัดการ พนักงาน): หน้าแรก · สินค้า · รับเข้า · จ่ายออก · เพิ่มเติม
- ผู้ดูอย่างเดียว: หน้าแรก · สินค้า · แจ้งเตือน · ประวัติ · เพิ่มเติม

เมนู **เพิ่มเติม** รวมเมนูที่เหลือ เช่น ปรับยอดสต็อก, ประวัติ, การแจ้งเตือน, รายงาน, สแกน, ผู้ใช้และสิทธิ์, ตั้งค่า และออกจากระบบ

**ไอคอนบนแถบบน**
- 🔍 **สแกน**: เปิดกล้องสแกนบาร์โค้ด/QR จากหน้าใดก็ได้
- 🔔 **กระดิ่ง**: ตัวเลขสีชมพูคือจำนวนแจ้งเตือนทั้งหมด (สต็อกต่ำ/หมด และล็อตใกล้หมดอายุ)

## 5. ร้านและสาขา

**ร้าน** คือธุรกิจ (เช่น Rose Beauty) ส่วน **สาขา** คือสถานที่ที่เก็บสต็อก (เช่น สาขาสยาม) สาขาทุกแห่งต้องอยู่ภายใต้ร้านเสมอ ระบบแสดงชื่อเต็มเป็น `ร้าน · สาขา` เช่น `Rose Beauty · สาขาสยาม`

### 5.1 สลับร้าน/สาขา
1. กดชื่อร้าน · สาขา (เมนูซ้าย, ใต้คำว่า CosmoStock บนแถบบน หรือในหน้า **เพิ่มเติม**)
2. เลือกร้านที่ต้องการ ระบบจะกลับไปหน้าแรกของร้านนั้น

ข้อมูลสินค้า สต็อก ประวัติ และผู้ใช้ **แยกกันเด็ดขาดในแต่ละสาขา** สินค้า SKU เดียวกันในสองสาขาถือเป็นคนละรายการ และมียอดของตัวเอง

### 5.2 เพิ่ม ลบ และเปลี่ยนชื่อสาขา (เจ้าของร้านขึ้นไปเท่านั้น)
ทำได้เฉพาะ **เจ้าของร้าน** ของร้านนั้น และ **ผู้ดูแลระบบ** ผู้จัดการ พนักงาน และผู้ดูอย่างเดียวจะไม่เห็นเมนูนี้
1. สลับไปที่สาขาใดก็ได้ของร้านที่ต้องการ แล้วไปที่ **ตั้งค่า** → การ์ด **ร้าน (ชื่อร้าน)**
2. **เปลี่ยนชื่อร้าน**: แก้ช่อง **ชื่อร้าน (ใช้ร่วมกันทุกสาขา)** แล้วกด **บันทึกชื่อร้าน**
3. **เพิ่มสาขา**: กดปุ่ม **＋ เพิ่มสาขา** (ที่การ์ดร้าน หรือในหน้าต่างเลือกร้าน/สาขา) พิมพ์ชื่อสาขา (เช่น `สาขาอารีย์`) แล้วกด **เพิ่มสาขา** ระบบจะสลับไปที่สาขาใหม่ทันที
4. **ลบสาขา**: กดไอคอนถังขยะข้างชื่อสาขา พิมพ์ชื่อสาขาเพื่อยืนยัน แล้วกด **ลบสาขาถาวร**

> - ชื่อสาขาห้ามซ้ำกันภายในร้านเดียวกัน
> - สาขาใหม่เริ่มต้นว่างเปล่า ต้องเพิ่มสินค้าและเชิญพนักงานแยกต่างหาก
> - การลบสาขาจะลบสินค้า ล็อต และประวัติของสาขานั้น **ถาวร** กู้คืนไม่ได้ ร้านต้องเหลืออย่างน้อย 1 สาขาเสมอ (ถ้าจะเลิกใช้ทั้งร้าน ให้ผู้ดูแลระบบลบร้าน)
> - **เพิ่มสาขา** ≠ **สร้างร้านใหม่**: เพิ่มสาขา = ที่ตั้งใหม่ของร้านเดิม (ชื่อร้านเดียวกัน) ส่วนสร้างร้านใหม่ = ธุรกิจใหม่ ข้อมูลแยกทั้งหมด (ปุ่ม **สร้างร้านใหม่** อยู่ที่การ์ด **ร้านและสาขาของฉัน**)

## 6. Dashboard (หน้าแรก)

| ส่วน | ความหมาย |
| --- | --- |
| **สินค้าทั้งหมด** | จำนวน SKU ที่ยังไม่ถูกลบ (กดเพื่อไปหน้าสินค้า) |
| **คงเหลือรวม** | ผลรวมจำนวนชิ้นของทุกสินค้า |
| **มูลค่าคลัง (ราคาทุน)** | ผลรวมของ คงเหลือ × ราคาทุน ของทุกสินค้า |
| **ใกล้หมด** | จำนวนสินค้าที่ 0 < คงเหลือ ≤ จุดสั่งซื้อ |
| **หมดสต็อก** | จำนวนสินค้าที่คงเหลือ 0 |
| **ใกล้หมดอายุ (≤ N วัน)** | จำนวนสินค้าที่มีล็อตหมดอายุภายใน N วัน (รวมล็อตที่หมดอายุแล้ว) |
| **กราฟสินค้าเข้า-ออก 6 เดือน** | สีลาเวนเดอร์ = รับเข้า, สีชมพู = จ่ายออก (หน่วยเป็นชิ้น) |
| **แจ้งเตือนสำคัญ** | ตัวอย่างสินค้าที่ต้องดูแล กด **ดูทั้งหมด** เพื่อไปหน้าแจ้งเตือน |
| **รายการเคลื่อนไหวล่าสุด** | 6 รายการล่าสุด พร้อมยอดก่อนและหลังทำรายการ |
| **มูลค่าคงคลังตามหมวดหมู่** | แถบเปรียบเทียบมูลค่าของแต่ละหมวด |

**ปุ่มลัด**: บนมือถือมีปุ่มรับเข้า / จ่ายออก / ปรับยอด / สแกน อยู่ด้านบน (แสดงตามสิทธิ์) ส่วนบนคอมพิวเตอร์มีช่องค้นหาสินค้าและปุ่มรับเข้า/จ่ายออกที่มุมขวาบน

## 7. สินค้า

### 7.1 รายการสินค้า ค้นหา และกรอง
- **ช่องค้นหา**: พิมพ์ชื่อ SKU หรือบาร์โค้ด รายการจะกรองให้ทันที ถ้ากด Enter (หรือใช้เครื่องยิงบาร์โค้ด) แล้วรหัสตรงกับสินค้า จะเปิดหน้าต่างผลการสแกนให้เลย
- **ปุ่มสแกน** ข้างช่องค้นหา: ใช้กล้องสแกน
- **สถานะ**: ทั้งหมด / ต้องดูแล (ทุกสถานะยกเว้นปกติ) / ปกติ / ใกล้หมด / หมด / ใกล้หมดอายุ / หมดอายุ
- **ชิปหมวดหมู่**: กรองตามหมวด
- **ส่งออก CSV**: ดาวน์โหลดรายการที่กรองอยู่ เปิดใน Excel แล้วภาษาไทยแสดงถูกต้อง

บนคอมพิวเตอร์รายการแสดงเป็นตาราง (มีปุ่มลัดรับเข้า/แก้ไข/ลบในแต่ละแถวตามสิทธิ์) ส่วนบนมือถือแสดงเป็นการ์ด

### 7.2 สถานะสินค้า
ระบบตัดสินสถานะตามลำดับนี้ และใช้สถานะแรกที่เข้าเงื่อนไข

| ลำดับ | สถานะ | เงื่อนไข |
| --- | --- | --- |
| 1 | **หมด** | คงเหลือ = 0 |
| 2 | **หมดอายุ** | มีล็อตที่เหลือของและเลยวันหมดอายุแล้ว |
| 3 | **ใกล้หมด** | คงเหลือ ≤ จุดสั่งซื้อ |
| 4 | **ใกล้หมดอายุ** | มีล็อตที่จะหมดอายุภายใน N วัน (N ตั้งได้ในหน้าตั้งค่าร้าน ค่าเริ่มต้น 60 วัน) |
| 5 | **ปกติ** | ไม่เข้าเงื่อนไขข้างบน |

### 7.3 หน้ารายละเอียดสินค้า
กดชื่อสินค้าเพื่อดู:
- ชื่อ หมวด SKU ราคาทุน ราคาขาย จุดสั่งซื้อ และสถานะ
- **คงเหลือ** (ถ้ามีขนาดบรรจุ จะแสดงแบบแตกหน่วยด้วย เช่น “2 ลัง 3 กล่อง 4 ชิ้น”), **มูลค่าคงคลัง**, **จำนวนล็อต**, **หมดอายุใกล้สุด**
- **QR Code** ของสินค้า (เข้ารหัสบาร์โค้ด หรือ SKU ถ้าไม่มีบาร์โค้ด)
- ปุ่ม **รับเข้า / จ่าย/เบิก / ปรับยอด / พิมพ์ฉลาก QR** (ตามสิทธิ์)
- ตาราง **ขนาดบรรจุ** (ถ้ามี)
- **ประวัติการเคลื่อนไหว** 20 รายการล่าสุด (กด “ดูทั้งหมด” เพื่อไปหน้าประวัติที่กรองสินค้านี้ไว้)
- **ล็อตสินค้า**: เลขล็อต วันที่รับเข้า วันหมดอายุ และคงเหลือของแต่ละล็อต

### 7.4 เพิ่มสินค้าใหม่ (เจ้าของร้าน, ผู้จัดการ)
1. หน้า **สินค้า** กด **เพิ่มสินค้า** (บนมือถือเป็นปุ่มลอยมุมขวาล่าง)
2. กรอกข้อมูล:

| ช่อง | บังคับ | คำอธิบาย |
| --- | :-: | --- |
| รูปสินค้า | | อัปโหลดจากเครื่องหรือถ่ายรูป ระบบย่อขนาดให้อัตโนมัติ |
| ชื่อสินค้า | ✓ | ไม่เกิน 120 ตัวอักษร |
| SKU | ✓ | ใช้ได้เฉพาะ A–Z, 0–9 และ `-` `_` `.` (ตัวเล็กจะถูกแปลงเป็นตัวใหญ่) ห้ามซ้ำในร้าน |
| หมวดหมู่ | | เลือกจากรายการ (สกินแคร์, เมคอัพ, บำรุงผิว, กันแดด, คลีนซิ่ง) หรือพิมพ์หมวดใหม่ได้เลย |
| บาร์โค้ด | | พิมพ์ หรือกดปุ่มสแกน ห้ามซ้ำกับสินค้าอื่นในร้าน |
| ราคาทุน / ราคาขาย | | บาท ใช้ทศนิยมได้ 2 ตำแหน่ง ราคาทุนใช้คำนวณมูลค่าคลัง |
| หน่วย | | หน่วยย่อยที่สุด เช่น ชิ้น ขวด หลอด (ค่าเริ่มต้น “ชิ้น”) |
| จุดสั่งซื้อ | | เมื่อคงเหลือไม่เกินค่านี้ จะขึ้นแจ้งเตือนสต็อกต่ำ |
| ติดตามล็อตและวันหมดอายุ | | ติ๊กถ้าสินค้ามีวันหมดอายุ ระบบจะถามเลขล็อตและวันหมดอายุตอนรับเข้า |
| ขนาดบรรจุ | | ดูหัวข้อ 7.5 |
| ยอดยกมา | | จำนวนที่มีอยู่แล้วตอนเริ่มใช้ระบบ (และเลขล็อต/วันหมดอายุ ถ้าติดตามล็อต) ระบบจะบันทึกเป็นรายการรับเข้าให้ |

3. กด **บันทึกสินค้า**

> ทางลัด: ถ้าสแกนบาร์โค้ดที่ยังไม่มีในระบบ เจ้าของร้าน/ผู้จัดการจะถูกถามว่าต้องการเพิ่มสินค้าใหม่ด้วยรหัสนี้หรือไม่ ถ้ากดเพิ่ม ระบบจะเติมบาร์โค้ดในฟอร์มให้

### 7.5 ขนาดบรรจุ (แพ็ค / กล่อง / ลัง)
ใช้เมื่อสินค้าเดียวกันมีหลายขนาดบรรจุ เช่น `กล่อง = 6 ชิ้น`, `ลัง = 24 ชิ้น`
- เพิ่มได้สูงสุด 5 ขนาดต่อสินค้า
- แต่ละขนาดมี **ชื่อหน่วย**, **บรรจุกี่หน่วยย่อย** (ตั้งแต่ 2 ขึ้นไป), **บาร์โค้ดของหน่วยนั้น** (ไม่บังคับ) และ **ราคาขาย** (ไม่บังคับ)
- ชื่อหน่วยและจำนวนบรรจุห้ามซ้ำกัน บาร์โค้ดห้ามซ้ำกับสินค้าอื่น
- **ประโยชน์**: เวลารับเข้า สแกนบาร์โค้ดลังแล้วกรอก “2” ระบบจะบวกให้ 48 ชิ้นเอง และยอดคงเหลือแสดงแบบแตกหน่วยได้

### 7.6 แก้ไขสินค้า (เจ้าของร้าน, ผู้จัดการ)
หน้ารายละเอียดสินค้า กด **แก้ไข** แล้วเปลี่ยนข้อมูลและกด **บันทึกสินค้า**

> แก้ **จำนวนคงเหลือ** ในหน้านี้ไม่ได้ ต้องทำผ่าน รับเข้า / จ่ายออก / ปรับยอด เท่านั้น เพื่อให้มีประวัติตรวจสอบย้อนหลังได้เสมอ

### 7.7 ลบสินค้า (เจ้าของร้าน, ผู้จัดการ)
1. หน้ารายละเอียดสินค้า กดไอคอนถังขยะ (หรือในตารางสินค้าบนคอมพิวเตอร์)
2. **พิมพ์ SKU ของสินค้า** เพื่อยืนยัน แล้วกด **ลบสินค้า**

สินค้าที่ลบจะหายจากรายการและการค้นหา แต่ **ประวัติการเคลื่อนไหวยังอยู่** (แสดงว่า “ลบแล้ว”) และยังนับในรายงานย้อนหลัง หลังลบแล้วสามารถนำ SKU และบาร์โค้ดเดิมไปใช้กับสินค้าใหม่ได้

## 8. รับเข้า จ่ายออก และปรับยอด

ทั้งสามแบบอยู่ในหน้าเดียว มีแท็บ **รับเข้า | จ่าย/เบิก | ปรับยอด** ด้านบน (แท็บที่ไม่มีสิทธิ์จะกดไม่ได้)

### 8.1 ขั้นตอนทั่วไป
1. **เลือกสินค้า** ด้วยวิธีใดวิธีหนึ่ง:
   - พิมพ์ชื่อ/SKU แล้วเลือกจากรายการ
   - ยิงบาร์โค้ดด้วยเครื่องยิงลงช่องค้นหา (เครื่องจะกด Enter ให้เอง)
   - กดปุ่มสแกนเพื่อใช้กล้อง
   - หรือเข้ามาจากปุ่ม รับเข้า/จ่าย/ปรับยอด ในหน้าสินค้า แจ้งเตือน หรือผลการสแกน (ระบบเลือกสินค้าให้แล้ว)
2. กรอกจำนวนและข้อมูลอื่นตามประเภท (ด้านล่าง)
3. ดูแถบล่าง **หลังบันทึก** ที่แสดง `ยอดเดิม → ยอดใหม่` ก่อนยืนยัน
4. กดปุ่มบันทึก ระบบจะแสดงเลขเอกสาร เช่น `บันทึก RCV-00042 แล้ว · 50 ชิ้น · คงเหลือ 145 ชิ้น`

ถ้าต้องการเปลี่ยนสินค้า กด ✕ ที่การ์ดสินค้าที่เลือกไว้

### 8.2 รับสินค้าเข้า (เลขเอกสาร `RCV-xxxxx`)
| ช่อง | คำอธิบาย |
| --- | --- |
| หน่วยที่ทำรายการ | ถ้าสินค้ามีขนาดบรรจุ เลือกหน่วย เช่น ชิ้น / กล่อง / ลัง (ถ้าสแกนบาร์โค้ดลัง ระบบเลือกให้เอง) |
| จำนวนที่รับเข้า | ตั้งแต่ 1 ขึ้นไป ใช้ปุ่ม − / + ได้ ถ้าเลือกหน่วยใหญ่จะแสดงว่าเท่ากับกี่หน่วยย่อย |
| เลขล็อต / วันหมดอายุ | แสดงเมื่อสินค้าติ๊ก “ติดตามล็อตและวันหมดอายุ” ถ้าเลขล็อตและวันหมดอายุตรงกับล็อตเดิม ระบบจะบวกเข้าล็อตเดิม |
| ผู้จำหน่าย / หมายเหตุ | กดชิปตัวอย่าง (เช่น “สั่งซื้อเพิ่ม”, “รับคืนจากลูกค้า”, “โอนจากสาขาอื่น”) หรือพิมพ์เอง |

### 8.3 จ่าย / เบิกสินค้า (เลขเอกสาร `ISS-xxxxx`)
- กรอก **จำนวนที่จ่ายออก** (ห้ามเกินคงเหลือ) และหน่วยที่ทำรายการ
- **ระบบตัดล็อตให้อัตโนมัติแบบ FEFO** (ล็อตที่หมดอายุก่อนจะถูกตัดก่อน ส่วนล็อตที่ไม่มีวันหมดอายุตัดท้ายสุด) และแสดงลำดับล็อตที่จะถูกตัดให้ดูก่อนบันทึก
- เหตุผลตัวอย่าง: ขายหน้าร้าน, ขายออนไลน์, เบิกใช้ในร้าน, ส่งสาขาอื่น, ทดลอง/แจกลูกค้า, ของเสีย/หมดอายุ

### 8.4 ปรับยอดสต็อก (เลขเอกสาร `ADJ-xxxxx`) — เจ้าของร้าน, ผู้จัดการ
ใช้เมื่อนับของจริงแล้วไม่ตรงกับระบบ
1. ระบบแสดง **ยอดในระบบตอนนี้**
2. กรอก **จำนวนที่นับได้จริง** (เป็นหน่วยย่อย) ระบบคำนวณส่วนต่าง (+/−) ให้
3. ถ้ายอดเพิ่มขึ้นและสินค้าติดตามล็อต ให้กรอกเลขล็อต/วันหมดอายุของของที่เกินมา ถ้ายอดลดลง ระบบตัดล็อตแบบ FEFO
4. **ต้องระบุเหตุผล** เช่น นับสต็อกประจำเดือน, สินค้าชำรุด/แตก, สินค้าสูญหาย, บันทึกผิดพลาด

> ถ้าจำนวนที่นับได้เท่ากับยอดในระบบ ระบบจะไม่ให้บันทึก เพราะไม่มีอะไรต้องปรับ

### 8.5 กฎสำคัญ
- **สต็อกติดลบไม่ได้**
- **ประวัติแก้ไขหรือลบไม่ได้** ถ้าบันทึกผิด ให้ทำรายการชดเชย (เช่น จ่ายออกผิด 5 ชิ้น ให้รับเข้า 5 ชิ้นพร้อมหมายเหตุ “แก้ไขรายการ ISS-xxxxx” หรือใช้การปรับยอด)
- เลขเอกสารรันต่อเนื่องแยกตามสาขาและประเภท

### 8.6 โอนสินค้าระหว่างสาขา
ระบบยังไม่มีฟังก์ชันโอนในขั้นตอนเดียว ให้ทำ 2 รายการ:
1. ที่สาขาต้นทาง: **จ่ายออก** เหตุผล “ส่งสาขาอื่น” แล้วระบุสาขาปลายทางในหมายเหตุ
2. ที่สาขาปลายทาง: **รับเข้า** เหตุผล “โอนจากสาขาอื่น” และใส่เลขเอกสาร ISS ของต้นทางในหมายเหตุ

## 9. สแกนบาร์โค้ดและ QR

### 9.1 วิธีสแกน
- **กล้องมือถือ/แท็บเล็ต**: กดไอคอนสแกน (แถบบน, หน้าแรก, หน้าสินค้า, ฟอร์มสินค้า, ฟอร์มรับเข้า/จ่ายออก) แล้วเล็งกล้องไปที่บาร์โค้ด เครื่องจะสั่นเมื่ออ่านได้
- **เครื่องยิงบาร์โค้ด (USB/Bluetooth)**: คลิกช่องค้นหาแล้วยิงได้เลย
- **พิมพ์เอง**: ในหน้าต่างสแกนมีช่องให้พิมพ์บาร์โค้ดหรือ SKU แล้วกด **ตกลง**

รองรับบาร์โค้ดทั่วไป (เช่น EAN-13, Code-128) และ QR Code โดยจะค้นจากบาร์โค้ดสินค้า, SKU และบาร์โค้ดของขนาดบรรจุ

### 9.2 ผลการสแกน
หน้าต่าง **ผลการสแกน** แสดง:
- ชื่อ หมวด SKU สถานะ และหน่วยที่สแกนได้ (เช่น “สแกนได้: ลัง (24 ชิ้น)”)
- คงเหลือในสาขานี้ คิดเป็นกี่ลัง/กล่อง ราคาขาย และจุดสั่งซื้อ
- ล็อตและวันหมดอายุ 3 ล็อตแรก
- **ยอดและล็อตในสาขาอื่น** (เจ้าของร้านและผู้จัดการ เมื่อมีหลายสาขา): ยอดรวม สถานะ และรายการล็อต (เลขล็อต วันหมดอายุ จำนวน) ของ SKU เดียวกันในแต่ละสาขาของร้าน ถ้าสแกน QR ล็อต จะบอกด้วยว่าล็อตนั้นเหลือที่แต่ละสาขาเท่าไร — ดูได้อย่างเดียว การรับเข้า/จ่ายออกยังทำเฉพาะสาขาที่เลือกอยู่ พนักงานคลังและผู้ดูอย่างเดียวเห็นเฉพาะสาขาของตัวเอง
- ความเคลื่อนไหวล่าสุด 3 รายการ
- ปุ่ม **ดูรายละเอียด / จ่ายออก / รับเข้า** (ปุ่มรับเข้า/จ่ายออกแสดงเฉพาะผู้มีสิทธิ์)

### 9.3 ถ้ากล้องเปิดไม่ได้
เบราว์เซอร์ยอมให้ใช้กล้องเฉพาะเว็บที่เปิดผ่าน **HTTPS** หรือ `localhost` ถ้าเปิดจากมือถือด้วย `http://192.168.x.x:3000` กล้องจะใช้ไม่ได้ (ยังพิมพ์รหัสเองได้) ให้ผู้ดูแลระบบเปิดใช้ HTTPS ดูวิธีใน `doc/HANDOVER.md`

อีกกรณีคือยังไม่ได้อนุญาตกล้อง ให้เข้าไปตั้งค่าเบราว์เซอร์แล้วอนุญาตกล้องสำหรับเว็บนี้

## 10. พิมพ์ฉลาก QR

1. หน้ารายละเอียดสินค้า กด **พิมพ์ฉลาก QR**
2. เลือก **หน่วย** ที่ต้องการพิมพ์ฉลาก (หน่วยย่อย หรือขนาดบรรจุที่มีบาร์โค้ด)
3. ตั้ง **จำนวนฉลาก** (1–60) และเลือกว่าจะ **แสดงราคา** หรือไม่
4. ดูตัวอย่าง แล้วกด **พิมพ์** และเลือกเครื่องพิมพ์ หรือ “บันทึกเป็น PDF”

ฉลากกว้าง 60 มม. มี QR ชื่อสินค้า SKU บาร์โค้ด และราคา (ถ้าเลือก)

> ขนาดบรรจุที่ยังไม่มีบาร์โค้ดจะพิมพ์ฉลากไม่ได้ ให้เพิ่มบาร์โค้ดในหน้าแก้ไขสินค้าก่อน

## 11. ประวัติการเคลื่อนไหว

แสดงทุกการรับเข้า/จ่ายออก/ปรับยอดของสาขา เรียงจากใหม่ไปเก่า
- **ค้นหา**: ชื่อสินค้า, SKU, เลขเอกสาร หรือเลขล็อต
- **ช่วงเวลา**: 7 วัน / 30 วัน (ค่าเริ่มต้น) / 90 วัน / 1 ปี / ทั้งหมด / กำหนดเอง
- **ประเภท**: ทั้งหมด / รับเข้า / จ่ายออก / ปรับยอด
- **กรองสินค้าเดียว**: เข้ามาจาก “ดูทั้งหมด” ในหน้าสินค้า (กด ✕ ที่ชิปชื่อสินค้าเพื่อยกเลิก)
- **โหลดเพิ่ม**: ครั้งละ 50 รายการ
- **ส่งออก CSV**: ตามตัวกรองปัจจุบัน สูงสุด 1,000 รายการต่อไฟล์

แต่ละรายการแสดง วันเวลา, ประเภท, เลขเอกสาร, ผู้ทำรายการ, จำนวน (+/−), หน่วยบรรจุที่ใช้, ยอดก่อน → หลัง, ล็อต และหมายเหตุ

## 12. แจ้งเตือน

มี 2 แท็บ:
- **สต็อกใกล้หมด**: สินค้าที่คงเหลือ ≤ จุดสั่งซื้อ (รวมสินค้าหมด) มีแถบแสดงคงเหลือเทียบกับจุดสั่งซื้อ และปุ่ม **รับเข้า** ลัด
- **ใกล้หมดอายุ**: ล็อตที่ยังมีของและจะหมดอายุภายใน N วัน รวมล็อตที่หมดอายุแล้ว แสดงเลขล็อต จำนวน วันหมดอายุ และจำนวนวันที่เหลือ

แจ้งเตือนคำนวณสดจากข้อมูลทุกครั้งที่เปิด ไม่ต้องกดรีเฟรชข้อมูลเอง

**วิธีจัดการ**
- สต็อกต่ำ: รับสินค้าเข้า หรือถ้าตั้งจุดสั่งซื้อสูงเกินไป ให้แก้จุดสั่งซื้อในหน้าแก้ไขสินค้า
- ล็อตหมดอายุ: นำของออกด้วย **จ่ายออก** เหตุผล “ของเสีย/หมดอายุ” (ระบบตัดล็อตที่หมดอายุก่อนให้อยู่แล้ว) หรือใช้ **ปรับยอด**
- เปลี่ยนจำนวนวันแจ้งเตือนล่วงหน้า: หน้า **ตั้งค่า** (เจ้าของร้าน)

## 13. รายงาน

(เจ้าของร้าน, ผู้จัดการ, ดูอย่างเดียว)

1. เลือกช่วงวันที่ **ตั้งแต่ – ถึง** หรือกดชิป: เดือนนี้ / เดือนก่อน / 90 วัน / ปีนี้
2. เลือกแท็บรายงาน:

| แท็บ | เนื้อหา |
| --- | --- |
| **สต็อกคงเหลือ** | ทุกสินค้า: SKU หมวด คงเหลือ ราคาทุน มูลค่า สถานะ พร้อมยอดรวม (เป็นยอด ณ ปัจจุบัน) |
| **เคลื่อนไหวตามช่วงเวลา** | ต่อสินค้า: รับเข้า จ่ายออก ปรับยอด ในช่วงที่เลือก และคงเหลือปัจจุบัน เรียงจากเคลื่อนไหวมากสุด |
| **สินค้าใกล้หมดอายุ** | ล็อตที่จะหมดอายุภายใน N วัน |
| **มูลค่าคลังตามหมวด** | ต่อหมวด: จำนวน SKU คงเหลือ รับเข้า จ่ายออก และมูลค่าคงเหลือ |

3. การ์ดสรุปด้านบน: รับเข้าทั้งช่วง, จ่ายออกทั้งช่วง, ปรับยอดสุทธิ และมูลค่าคลังปัจจุบัน
4. **ส่งออก Excel (CSV)**: ดาวน์โหลดแท็บที่เปิดอยู่
5. **PDF / พิมพ์**: เปิดหน้าต่างพิมพ์ (เลือก “บันทึกเป็น PDF” ได้) ระบบซ่อนปุ่มและเมนูตอนพิมพ์ให้เอง

> มูลค่าคลังคิดจาก **ราคาทุนปัจจุบัน** ของสินค้า ไม่ใช่ราคาทุนตอนรับเข้าแต่ละล็อต

## 14. ผู้ใช้และสิทธิ์

(เจ้าของร้านเท่านั้น) จัดการสมาชิกของ **สาขาที่เลือกอยู่**

### 14.1 ดูสมาชิก
ตารางแสดงชื่อ อีเมล บทบาท และเวลาเข้าใช้ล่าสุดของแต่ละคน ด้านขวามีตารางสิทธิ์ตามบทบาทไว้อ้างอิง

### 14.2 เชิญผู้ใช้เข้าร้าน
1. กด **เชิญผู้ใช้**
2. กรอก **อีเมล**, **ชื่อ-นามสกุล**, เลือก **บทบาท** (ค่าเริ่มต้นคือพนักงานคลัง)
3. **รหัสผ่านเริ่มต้น**: ระบบสุ่มให้ (กด “สุ่มใหม่” ได้) หรือพิมพ์เอง อย่างน้อย 8 ตัวอักษร
4. กด **เพิ่มเข้าร้าน**
5. ถ้าเป็นบัญชีใหม่ ระบบแสดงอีเมลและรหัสผ่านให้ กด **คัดลอก** แล้วส่งให้ผู้ใช้ (เช่น ทาง LINE) และแนะนำให้เปลี่ยนรหัสผ่านหลังเข้าใช้ครั้งแรก

> ถ้าอีเมลนั้นมีบัญชีอยู่แล้ว (เช่น เป็นพนักงานอีกสาขา) ระบบเพิ่มเข้าร้านโดยใช้รหัสผ่านเดิมของเขา และไม่สร้างบัญชีใหม่

### 14.3 เปลี่ยนบทบาท
เลือกบทบาทใหม่จากช่องเลือกในแถวของผู้ใช้ ระบบบันทึกทันที
- เปลี่ยนบทบาทตัวเองไม่ได้
- ร้านต้องมีเจ้าของร้านอย่างน้อย 1 คน
- ⚠️ การตั้งใครเป็น **เจ้าของร้าน** ทำให้คนนั้นเป็นเจ้าของ **ทุกสาขาในธุรกิจ** รวมถึงจัดการผู้ใช้ ลบสินค้า และเพิ่มสาขาได้ ควรให้เฉพาะคนที่ไว้ใจได้

### 14.4 ตั้งรหัสผ่านใหม่ให้ผู้ใช้
1. กดไอคอน **กุญแจ** ในแถวของผู้ใช้
2. ใช้รหัสที่สุ่มให้หรือพิมพ์เอง แล้วกด **บันทึกรหัสผ่าน**
3. ส่งรหัสใหม่ให้ผู้ใช้ ผู้ใช้จะถูกออกจากระบบทุกอุปกรณ์

> ถ้าผู้ใช้คนนั้นเป็นสมาชิกร้านอื่นที่คุณไม่ได้เป็นเจ้าของด้วย ระบบไม่ให้รีเซ็ต (เพื่อความปลอดภัยของร้านอื่น) ให้เจ้าตัวเปลี่ยนเองจากหน้าตั้งค่า

### 14.5 นำผู้ใช้ออกจากร้าน
กดไอคอน **ถังขยะ** แล้วยืนยัน ผู้ใช้จะเข้าดูข้อมูลสาขานี้ไม่ได้อีก แต่บัญชีและประวัติที่เขาเคยบันทึกยังอยู่ นำตัวเองออกไม่ได้

## 15. ตั้งค่า

### 15.1 ตั้งค่าสาขา (ผู้มีสิทธิ์ตั้งค่าร้าน)
- **ชื่อสาขา** (ชื่อร้านเปลี่ยนได้เฉพาะเจ้าของร้าน ที่การ์ดร้าน ดูหัวข้อ 5.2)
- **แจ้งเตือนสินค้าใกล้หมดอายุล่วงหน้า (วัน)**: 1–730 วัน ค่าเริ่มต้น 60 วัน ตั้งแยกได้ในแต่ละสาขา
- จุดสั่งซื้อ (สต็อกต่ำ) ตั้งในหน้าแก้ไขสินค้าแต่ละตัว

### 15.2 บัญชีของฉัน (ทุกคน)
แก้ **ชื่อที่แสดง** ซึ่งจะไปแสดงในประวัติรายการที่บันทึกหลังจากนี้ (รายการเก่ายังเป็นชื่อเดิม)

### 15.3 เปลี่ยนรหัสผ่าน (ทุกคน)
กรอกรหัสผ่านปัจจุบัน รหัสผ่านใหม่ (อย่างน้อย 8 ตัวอักษร) และยืนยัน แล้วกด **เปลี่ยนรหัสผ่าน** อุปกรณ์อื่นที่เข้าสู่ระบบไว้จะถูกออกจากระบบ

### 15.4 ร้านและสาขาของฉัน
แสดงทุกร้าน/สาขาที่เข้าถึงได้พร้อมบทบาท กดเพื่อสลับ และเจ้าของร้านสร้างร้านใหม่ได้ที่นี่ ส่วนการเพิ่ม/ลบสาขาอยู่ที่การ์ดร้าน (หัวข้อ 5.2)

### 15.5 สวมสิทธิ์ผู้ใช้ (ผู้ดูแลระบบเท่านั้น)
ใช้ตรวจปัญหาหรือช่วยผู้ใช้ โดยเห็นหน้าจอและทำได้ **เท่าที่ผู้ใช้นั้นทำได้**
1. **ผู้ดูแลระบบ** → ตารางผู้ใช้ทั้งหมด → กดไอคอนรูปตา 👁 ที่แถวของผู้ใช้ → **สวมสิทธิ์**
2. ระหว่างสวมสิทธิ์จะมีแถบสีด้านบนบอกว่ากำลังเป็นใคร รายการที่บันทึกจะมีชื่อผู้ใช้ตามด้วย `(สวมสิทธิ์โดย อีเมลผู้ดูแลระบบ)` ในประวัติ
3. เสร็จแล้วกด **กลับเป็นผู้ดูแลระบบ** ที่แถบด้านบน (ถ้าลืม จะหมดอายุเองใน 2 ชั่วโมง)

> สวมสิทธิ์ผู้ดูแลระบบคนอื่นไม่ได้ และระหว่างสวมสิทธิ์จะเปลี่ยนรหัสผ่านหรือชื่อบัญชีของผู้ใช้นั้นไม่ได้ การสวมสิทธิ์ไม่นับเป็นการเข้าใช้ล่าสุดของผู้ใช้

## 16. คำถามที่พบบ่อยและการแก้ปัญหา

| ปัญหา | สาเหตุ / วิธีแก้ |
| --- | --- |
| เข้าสู่ระบบไม่ได้ “อีเมลหรือรหัสผ่านไม่ถูกต้อง” | ตรวจตัวพิมพ์และภาษาแป้นพิมพ์ ถ้าลืมให้ดูหัวข้อ 3.3 |
| “พยายามเข้าสู่ระบบผิดหลายครั้ง” | รอ 10 นาทีแล้วลองใหม่ |
| ไม่เห็นเมนูรับเข้า/รายงาน/ผู้ใช้ | บทบาทไม่มีสิทธิ์ หรือเลือกร้านผิด ให้ตรวจบทบาทที่มุมซ้ายล่างหรือหน้าเพิ่มเติม |
| กล้องสแกนไม่ทำงาน | ต้องเปิดผ่าน HTTPS/localhost และอนุญาตกล้อง (หัวข้อ 9.3) ระหว่างนี้พิมพ์รหัสเองได้ |
| สแกนแล้ว “ไม่พบสินค้า” | บาร์โค้ดยังไม่ได้ผูกกับสินค้า ให้แก้ไขสินค้าแล้วใส่บาร์โค้ด หรือเพิ่มสินค้าใหม่ |
| บันทึกจ่ายออกไม่ได้ “จำนวนคงเหลือไม่พอ” | จ่ายเกินยอดคงเหลือ ตรวจจำนวนและหน่วยที่เลือก (เช่น เลือก “ลัง” แทน “ชิ้น”) |
| บันทึกรายการผิด | ประวัติลบไม่ได้ ให้ทำรายการชดเชย (หัวข้อ 8.5) |
| “SKU … มีอยู่แล้วในร้านนี้” / “บาร์โค้ด … ถูกใช้แล้ว” | ใช้ SKU/บาร์โค้ดอื่น หรือแก้สินค้าที่มีอยู่แทน |
| เปิด CSV ใน Excel แล้วภาษาไทยเพี้ยน | เปิดด้วยการดับเบิลคลิกไฟล์ หรือใช้ Data → From Text/CSV แล้วเลือก UTF-8 |
| “เชื่อมต่อเซิร์ฟเวอร์ไม่ได้” | เครื่องเซิร์ฟเวอร์ปิดอยู่ หรือมือถือไม่ได้ต่อ Wi-Fi เดียวกัน |
| รูปสินค้าไม่ขึ้น / “รูปมีขนาดใหญ่เกินไป” | ใช้ไฟล์ JPG/PNG/WebP ระบบย่อรูปให้อัตโนมัติ ถ้ายังใหญ่เกินให้ลองรูปอื่น |
| ตัวเลขแจ้งเตือนไม่ลดลง | ต้องรับเข้าให้เกินจุดสั่งซื้อ หรือนำล็อตหมดอายุออกจนเหลือ 0 |

| **จุดสั่งซื้อ** | ยอดคงเหลือขั้นต่ำ ถ้าเหลือไม่เกินค่านี้จะแจ้งเตือนให้สั่งเพิ่ม |
| **ขนาดบรรจุ** | หน่วยใหญ่ที่ประกอบด้วยหน่วยย่อยหลายชิ้น เช่น กล่อง ลัง |
| **ยอดยกมา** | ยอดสินค้าที่มีอยู่ก่อนเริ่มใช้ระบบ |
| **RCV / ISS / ADJ** | เลขเอกสารของรับเข้า / จ่ายออก / ปรับยอด |
| **มูลค่าคลัง** | คงเหลือ × ราคาทุน |
| **สาขา / ร้าน** | หน่วยที่มีสต็อกและผู้ใช้แยกกัน หลายสาขารวมกันเป็นหนึ่งธุรกิจ |
