# คู่มือผู้ดูอย่างเดียว (Viewer)

> สิทธิ์ของคุณ: **ดูข้อมูลและรายงาน** ในสาขาที่ได้รับเชิญ โดยแก้ไขข้อมูลใดๆ ไม่ได้
> เหมาะสำหรับฝ่ายบัญชี ผู้ตรวจสอบ หรืออาจารย์/ผู้ประเมิน
> รายละเอียดเชิงลึกของแต่ละหน้าดูได้ใน [คู่มือฉบับรวม](../USER_GUIDE.md)

| ทำได้ | ทำไม่ได้ |
| --- | --- |
| ดู Dashboard / สินค้า / รายละเอียดสินค้า / ล็อต | เพิ่ม / แก้ไข / ลบสินค้า |
| ดูประวัติการเคลื่อนไหว | รับเข้า / จ่ายออก / ปรับยอด |
| ดูแจ้งเตือน | จัดการผู้ใช้ / ตั้งค่าร้าน |
| **ดูรายงาน และส่งออก CSV / PDF** | |
| สแกนบาร์โค้ดดูข้อมูลสินค้า, พิมพ์ฉลาก QR | |
| แก้ชื่อตัวเอง / เปลี่ยนรหัสผ่านตัวเอง | |

**เมนูล่างบนมือถือ**: หน้าแรก · สินค้า · แจ้งเตือน · ประวัติ · เพิ่มเติม (รายงานอยู่ในเมนู **เพิ่มเติม**)

---

## 1. เข้าใช้งานครั้งแรก

1. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่เจ้าของร้านให้มา
2. **ตั้งค่า** (หรือ **เพิ่มเติม** → ตั้งค่าบัญชี · รหัสผ่าน) → **เปลี่ยนรหัสผ่าน**
3. ถ้าได้รับสิทธิ์หลายสาขา ให้กดชื่อร้านด้านบนเพื่อสลับสาขา

---

## 2. ดูภาพรวม (Dashboard)

| ตัวเลข | ความหมาย |
| --- | --- |
| สินค้าทั้งหมด | จำนวน SKU |
| คงเหลือรวม | จำนวนชิ้นรวมทุกสินค้า |
| มูลค่าคลัง | คงเหลือ × ราคาทุน (ราคาทุนปัจจุบัน) |
| ใกล้หมด / หมดสต็อก | จำนวนสินค้าที่ต่ำกว่าหรือเท่ากับจุดสั่งซื้อ / เหลือ 0 |
| ใกล้หมดอายุ | จำนวนสินค้าที่มีล็อตหมดอายุภายใน N วัน (รวมที่หมดอายุแล้ว) |

กราฟแสดงการรับเข้า (ลาเวนเดอร์) และจ่ายออก (ชมพู) ย้อนหลัง 6 เดือน และมูลค่าตามหมวดหมู่

---

## 3. ตรวจสอบสินค้า

- **สินค้า**: ค้นหาด้วยชื่อ/SKU/บาร์โค้ด และกรองตามสถานะหรือหมวด
- เปิดสินค้าเพื่อดูยอดคงเหลือ มูลค่า ล็อตทั้งหมดพร้อมวันหมดอายุ และประวัติ 20 รายการล่าสุด
- **สแกน** (ไอคอนบนแถบบน): ดูข้อมูลสินค้าจากบาร์โค้ด ในหน้าต่างผลการสแกนจะมีปุ่ม **ดูรายละเอียด** อย่างเดียว

---

## 4. ตรวจสอบประวัติ (Audit)

**ประวัติการเคลื่อนไหว** เก็บทุกรายการแบบ **แก้ไขหรือลบไม่ได้** ใช้ตรวจสอบได้ดังนี้
- กรองตาม **ช่วงเวลา** (7 วัน ถึงทั้งหมด หรือกำหนดเอง) และ **ประเภท** (รับเข้า / จ่ายออก / ปรับยอด)
- ค้นหาด้วยชื่อสินค้า SKU **เลขเอกสาร** หรือ **เลขล็อต**
- ทุกรายการมี: วันเวลา ผู้ทำรายการ เลขเอกสาร จำนวน ยอดก่อน → หลัง และหมายเหตุ/เหตุผล
- **ส่งออก CSV** ได้สูงสุด 1,000 รายการต่อครั้ง (ถ้ามากกว่านั้นให้แบ่งช่วงวันที่)

**จุดที่ควรตรวจ**
- รายการ **ปรับยอด (ADJ)** ทุกรายการ ต้องมีเหตุผลกำกับ
- ยอด **ก่อน → หลัง** ของแต่ละรายการต้องต่อเนื่องกันในสินค้าเดียวกัน
- การจ่ายออกด้วยเหตุผล “ของเสีย/หมดอายุ” หรือ “ทดลอง/แจกลูกค้า” ที่มากผิดปกติ

---

## 5. รายงาน

1. **เพิ่มเติม** → **รายงาน** (คอมพิวเตอร์: เมนูซ้าย)
2. เลือกช่วงวันที่ หรือกด เดือนนี้ / เดือนก่อน / 90 วัน / ปีนี้
3. เลือกแท็บ:
   - **สต็อกคงเหลือ**: ยอดและมูลค่าปัจจุบันของทุกสินค้า
   - **เคลื่อนไหวตามช่วงเวลา**: รับเข้า/จ่ายออก/ปรับยอดต่อสินค้าในช่วงที่เลือก
   - **สินค้าใกล้หมดอายุ**: ล็อตที่ต้องจัดการ
   - **มูลค่าคลังตามหมวด**
4. กด **ส่งออก Excel (CSV)** หรือ **PDF / พิมพ์**

> แท็บสต็อกคงเหลือและมูลค่าคลังเป็นยอด **ณ วันนี้** เสมอ ส่วนช่วงวันที่มีผลกับตัวเลขรับเข้า/จ่ายออก/ปรับยอด

---

## 6. ข้อควรรู้

- ถ้าพบข้อมูลผิดปกติ ให้แจ้งเจ้าของร้านหรือผู้จัดการ เพราะคุณแก้ไขข้อมูลเองไม่ได้
- เปิดลิงก์หน้าที่ไม่มีสิทธิ์ (เช่น หน้ารับเข้า) จะเห็นข้อความว่าไม่มีสิทธิ์ ซึ่งเป็นการทำงานปกติ
