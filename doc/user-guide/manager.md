# คู่มือผู้จัดการ (Manager)

> สิทธิ์ของคุณ: **ดูแลสินค้าและสต็อก และดูรายงาน** ในสาขาที่ได้รับเชิญ
> รายละเอียดเชิงลึกของแต่ละหน้าดูได้ใน [คู่มือฉบับรวม](../USER_GUIDE.md)

| ทำได้ | ทำไม่ได้ |
| --- | --- |
| ดู Dashboard / สินค้า / ประวัติ / แจ้งเตือน | จัดการผู้ใช้และสิทธิ์ |
| **เพิ่ม / แก้ไข / ลบสินค้า** | ตั้งค่าร้าน (ชื่อร้าน, วันแจ้งเตือน) |
| **รับเข้า / จ่ายออก / ปรับยอด** | เพิ่มสาขาใหม่ |
| **ดูรายงาน / ส่งออก CSV / PDF** | |
| ดูยอดสินค้าในสาขาอื่นที่คุณอยู่ (ตอนสแกน) | |
| แก้ชื่อตัวเอง / เปลี่ยนรหัสผ่านตัวเอง | |

ถ้าต้องการเพิ่มหรือนำพนักงานออก เปลี่ยนชื่อร้าน หรือเปลี่ยนจำนวนวันแจ้งเตือน ให้แจ้งเจ้าของร้าน

---

## 1. เข้าใช้งานครั้งแรก

1. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่เจ้าของร้านให้มา
2. ไปที่ **ตั้งค่า** → **เปลี่ยนรหัสผ่าน** แล้วตั้งรหัสผ่านของตัวเอง
3. ถ้าดูแลหลายสาขา ให้กดชื่อร้าน (เมนูซ้ายหรือแถบบน) เพื่อสลับสาขา

---

## 2. งานประจำวัน

| เวลา | งาน | เมนู |
| --- | --- | --- |
| เปิดร้าน | ดูแจ้งเตือนสต็อกต่ำและของใกล้หมดอายุ | 🔔 **แจ้งเตือน** |
| ระหว่างวัน | รับของจากผู้จำหน่าย | **รับสินค้าเข้า** |
| ระหว่างวัน | จ่ายของ / เบิก / ส่งสาขาอื่น | **จ่าย/เบิกสินค้า** |
| สินค้าใหม่เข้าร้าน | สร้างสินค้าและพิมพ์ฉลาก | **สินค้า** → **เพิ่มสินค้า** |
| ปิดร้าน | ตรวจรายการที่ทีมบันทึก | **ประวัติการเคลื่อนไหว** |
| สิ้นเดือน | นับสต็อก ปรับยอด ส่งออกรายงาน | **ปรับยอดสต็อก**, **รายงาน** |

---

## 3. สินค้า

### เพิ่มสินค้า
1. **สินค้า** → **เพิ่มสินค้า** (บนมือถือเป็นปุ่มลอยมุมขวาล่าง)
2. กรอก **ชื่อสินค้า** และ **SKU** (บังคับ) แล้วกรอกหมวดหมู่ บาร์โค้ด (กดสแกนได้) ราคาทุน ราคาขาย หน่วย และ **จุดสั่งซื้อ**
3. ติ๊ก **ติดตามล็อตและวันหมดอายุ** ถ้าสินค้ามีวันหมดอายุ
4. **ขนาดบรรจุ** (ไม่บังคับ): เช่น กล่อง = 6 ชิ้น พร้อมบาร์โค้ดกล่อง
5. **ยอดยกมา** (ไม่บังคับ): ยอดที่มีอยู่แล้ว พร้อมเลขล็อต/วันหมดอายุ
6. กด **บันทึกสินค้า**

> ทางลัด: สแกนบาร์โค้ดที่ยังไม่มีในระบบ แล้วระบบจะถามว่าต้องการเพิ่มสินค้าใหม่ด้วยรหัสนี้หรือไม่

### แก้ไขสินค้า
เปิดสินค้า → **แก้ไข** แก้ยอดคงเหลือในฟอร์มนี้ไม่ได้ ต้องใช้การรับเข้า/จ่ายออก/ปรับยอด

### ลบสินค้า
1. เปิดสินค้า แล้วกดไอคอนถังขยะ
2. พิมพ์ SKU เพื่อยืนยัน แล้วกด **ลบสินค้า**
- สินค้าจะหายจากรายการ แต่ประวัติยังอยู่และยังนับในรายงาน
- SKU และบาร์โค้ดเดิมนำไปใช้กับสินค้าใหม่ได้

### พิมพ์ฉลาก QR
เปิดสินค้า → **พิมพ์ฉลาก QR** → เลือกหน่วย จำนวนฉลาก (สูงสุด 60) และเลือกว่าจะแสดงราคาหรือไม่ → **พิมพ์**

---

## 4. รับเข้า / จ่ายออก / ปรับยอด

1. เลือกสินค้า โดยพิมพ์ชื่อ/SKU, ยิงบาร์โค้ด หรือกดปุ่มสแกน
2. ถ้ามีขนาดบรรจุ ให้เลือก **หน่วยที่ทำรายการ** (ชิ้น / กล่อง / ลัง)
3. กรอกจำนวน แล้วดูแถบล่าง `ยอดเดิม → ยอดใหม่`
4. **รับเข้า**: กรอกเลขล็อต + วันหมดอายุ (ถ้าสินค้าติดตามล็อต) และผู้จำหน่าย
   **จ่ายออก**: เลือกเหตุผล ระบบตัดล็อตที่หมดอายุก่อนให้ (FEFO)
   **ปรับยอด**: กรอก **จำนวนที่นับได้จริง** และ **เหตุผล (บังคับ)**
5. กดบันทึก ระบบแสดงเลขเอกสาร (RCV / ISS / ADJ)

**บันทึกผิด?** ประวัติลบไม่ได้ ให้ทำรายการชดเชย แล้วเขียนหมายเหตุ เช่น “แก้ไขรายการ ISS-00103”

ดูรายละเอียดเพิ่มเติมใน [คู่มือรวม หัวข้อ 8](../USER_GUIDE.md#8-รับเข้า-จ่ายออก-และปรับยอด)

---

## 5. นับสต็อกประจำเดือน

1. ส่งออกรายการสินค้า: **สินค้า** → **ส่งออก CSV** แล้วพิมพ์เป็นใบนับ
2. นับของจริง
3. สินค้าที่ยอดไม่ตรง: **ปรับยอดสต็อก** → เลือกสินค้า → กรอกจำนวนที่นับได้ → เหตุผล “นับสต็อกประจำเดือน”
4. ส่งออก **รายงาน → สต็อกคงเหลือ** เก็บไว้เป็นหลักฐาน

---

## 6. แจ้งเตือนและรายงาน

- **แจ้งเตือน → สต็อกใกล้หมด**: กด **รับเข้า** จากการ์ดได้ทันที ถ้าจุดสั่งซื้อไม่เหมาะ ให้แก้ในหน้าแก้ไขสินค้า
- **แจ้งเตือน → ใกล้หมดอายุ**: ล็อตที่หมดอายุแล้วให้จ่ายออกด้วยเหตุผล “ของเสีย/หมดอายุ”
- **รายงาน**: เลือกช่วงวันที่และแท็บ แล้วกด **ส่งออก Excel (CSV)** หรือ **PDF / พิมพ์**

---

## 7. ข้อควรรู้

- หน้า **ตั้งค่า** ของคุณมีแค่ **บัญชีของฉัน**, **เปลี่ยนรหัสผ่าน** และ **ร้านของฉัน** (สลับสาขา) การเพิ่ม ลบ และเปลี่ยนชื่อร้าน/สาขา ทำได้เฉพาะเจ้าของร้าน
- เมื่อสแกนสินค้า คุณจะเห็นยอดและล็อต (เลขล็อต วันหมดอายุ จำนวน) ของ SKU เดียวกันในสาขาอื่นที่คุณเป็นสมาชิกอยู่ ถ้าสแกน QR ล็อตจะเห็นว่าล็อตนั้นเหลือที่สาขาไหนเท่าไร
- ถ้าพนักงานลืมรหัสผ่าน ให้แจ้งเจ้าของร้าน
