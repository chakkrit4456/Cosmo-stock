> รายละเอียดเชิงลึกของแต่ละหน้าดูได้ใน [คู่มือฉบับรวม](../USER_GUIDE.md)

| ทำได้ | หมายเหตุ |
| --- | --- |

| เพิ่ม แก้ไข และ **ลบ** สินค้า | ลบได้เฉพาะเจ้าของร้าน |

## 1. เริ่มต้นครั้งแรก (ร้านใหม่)

ลำดับที่แนะนำเมื่อเริ่มใช้ระบบ

1. **รับบัญชีจากผู้ดูแลระบบ**: ระบบไม่มีหน้าสมัคร ผู้ดูแลระบบจะสร้างร้านและบัญชีเจ้าของร้านให้ แล้วส่งอีเมลและรหัสผ่านเริ่มต้นมา
   (ถ้าได้บัญชีแอดมินตัวอย่างมา ให้เข้าสู่ระบบแล้ว **เปลี่ยนรหัสผ่านทันที** ที่ ตั้งค่า → เปลี่ยนรหัสผ่าน)
2. **ตั้งค่าร้าน**: **ตั้งค่า** → ตั้งชื่อร้าน และจำนวนวันแจ้งเตือนสินค้าใกล้หมดอายุ (ค่าเริ่มต้น 60 วัน)
3. **เพิ่มสินค้า**: **สินค้า** → **เพิ่มสินค้า** กรอกชื่อ SKU บาร์โค้ด ราคาทุน จุดสั่งซื้อ ติ๊ก “ติดตามล็อตและวันหมดอายุ” ถ้าสินค้ามีวันหมดอายุ และใส่ **ยอดยกมา** เป็นจำนวนที่มีอยู่ตอนนี้
4. **ตั้งขนาดบรรจุ** (ถ้ามี): เช่น กล่อง = 6 ชิ้น, ลัง = 24 ชิ้น พร้อมบาร์โค้ดของแต่ละขนาด
5. **พิมพ์ฉลาก QR**: ให้สินค้าที่ไม่มีบาร์โค้ด (หน้าสินค้า → **พิมพ์ฉลาก QR**)
6. **เชิญทีมงาน**: **ผู้ใช้และสิทธิ์** → **เชิญผู้ใช้** (ดูหัวข้อ 4)
7. **เพิ่มสาขาอื่น** (ถ้ามี): ดูหัวข้อ 5

## 2. งานประจำวัน

| งาน | ทำที่ไหน |
| --- | --- |
| ดูภาพรวม ยอดคงเหลือ มูลค่าคลัง | **Dashboard** |
| ดูสินค้าที่ต้องสั่งเพิ่ม / ใกล้หมดอายุ | กระดิ่ง 🔔 หรือ **แจ้งเตือน** |
| รับของจากผู้จำหน่าย | **รับสินค้าเข้า** (สแกนบาร์โค้ด → จำนวน → ล็อต/วันหมดอายุ → บันทึก) |
| ขาย / เบิก / ส่งสาขาอื่น | **จ่าย/เบิกสินค้า** (ระบบตัดล็อตที่หมดอายุก่อนให้) |
| นับสต็อก แล้วยอดไม่ตรง | **ปรับยอดสต็อก** (กรอกจำนวนที่นับได้จริง + เหตุผล) |
| ตรวจย้อนหลังว่าใครทำอะไร | **ประวัติการเคลื่อนไหว** |

ขั้นตอนละเอียดของการรับเข้า จ่ายออก และปรับยอด ดูได้ใน [คู่มือรวม หัวข้อ 8](../USER_GUIDE.md#8-รับเข้า-จ่ายออก-และปรับยอด)

## 3. จัดการสินค้า

### เพิ่มหรือแก้ไขสินค้า
- เพิ่ม: **สินค้า** → **เพิ่มสินค้า**
- แก้ไข: เปิดสินค้า → **แก้ไข**
- SKU ใช้ได้เฉพาะ A–Z, 0–9, `-` `_` `.` และห้ามซ้ำในสาขา
- แก้ยอดคงเหลือในฟอร์มนี้ไม่ได้ ต้องใช้ รับเข้า/จ่ายออก/ปรับยอด

### ลบสินค้า (เจ้าของร้านและผู้จัดการ)
1. เปิดสินค้า แล้วกดไอคอนถังขยะ
2. พิมพ์ SKU เพื่อยืนยัน แล้วกด **ลบสินค้า**
- สินค้าจะหายจากรายการ แต่ประวัติยังอยู่และยังนับในรายงาน
- SKU และบาร์โค้ดเดิมนำไปใช้กับสินค้าใหม่ได้

## 4. จัดการผู้ใช้และสิทธิ์

เมนู **ผู้ใช้และสิทธิ์** ใช้จัดการสมาชิกของ **สาขาที่เลือกอยู่** เท่านั้น ถ้าต้องการให้พนักงานคนเดียวกันทำงานหลายสาขา ให้สลับสาขาแล้วเชิญซ้ำด้วยอีเมลเดิม

### เลือกบทบาทให้เหมาะ
| บทบาท | เหมาะกับ | ทำได้ |
| --- | --- | --- |
| **ผู้จัดการ** | หัวหน้าสาขา | จัดการสินค้า (รวมลบ), รับเข้า/จ่ายออก/ปรับยอด, ดูรายงาน |
| **พนักงานคลัง** | พนักงานหน้าร้าน/คลัง | รับเข้า/จ่ายออก, ดูสินค้า/ประวัติ/แจ้งเตือน |
| **ดูอย่างเดียว** | บัญชี / ผู้ตรวจสอบ | ดูข้อมูลและรายงาน, แก้อะไรไม่ได้ |
| **เจ้าของร้าน** | หุ้นส่วนเท่านั้น | ทุกอย่าง **ทุกสาขา** |

> ⚠️ **ระวัง**: การตั้งใครเป็นเจ้าของร้านในสาขาใดสาขาหนึ่ง ทำให้คนนั้นเป็นเจ้าของ **ทุกสาขาในธุรกิจ** ทันที

### เชิญผู้ใช้
1. กด **เชิญผู้ใช้** แล้วกรอกอีเมล ชื่อ และบทบาท
2. ใช้รหัสผ่านเริ่มต้นที่ระบบสุ่มให้ หรือพิมพ์เอง (อย่างน้อย 8 ตัวอักษร)
3. กด **เพิ่มเข้าร้าน** แล้วกด **คัดลอก** ข้อมูลเข้าสู่ระบบไปส่งให้ผู้ใช้
4. บอกผู้ใช้ให้เปลี่ยนรหัสผ่านหลังเข้าใช้ครั้งแรก

ถ้าอีเมลนั้นมีบัญชีอยู่แล้ว ระบบเพิ่มเข้าร้านโดยใช้รหัสผ่านเดิมของเขา

### งานอื่น
- **เปลี่ยนบทบาท**: เลือกจากช่องบทบาทในแถวของผู้ใช้ (เปลี่ยนของตัวเองไม่ได้)
- **ผู้ใช้ลืมรหัสผ่าน**: กดไอคอน 🔑 → **บันทึกรหัสผ่าน** แล้วส่งรหัสใหม่ให้ (ผู้ใช้จะถูกออกจากระบบทุกเครื่อง)
- **พนักงานลาออก**: กดไอคอน 🗑 เพื่อนำออกจากร้าน ประวัติที่เขาบันทึกไว้ยังอยู่ครบ
- ร้านต้องมีเจ้าของร้านอย่างน้อย 1 คนเสมอ

## 5. หลายสาขา

สาขาทุกแห่งอยู่ภายใต้ร้าน ระบบแสดงเป็น `ร้าน · สาขา` เช่น `Rose Beauty · สาขาสยาม` การเพิ่ม ลบ และเปลี่ยนชื่อร้าน ทำได้เฉพาะเจ้าของร้าน (และผู้ดูแลระบบ)

### เพิ่มสาขา
1. **ตั้งค่า** → การ์ด **ร้าน (ชื่อร้าน)** → ปุ่ม **＋ เพิ่มสาขา** (หรือกดชื่อร้านด้านบน → **เพิ่มสาขาใน …**)
2. พิมพ์ชื่อสาขา เช่น `สาขาอารีย์` แล้วกด **เพิ่มสาขา**
   - ปุ่ม **สร้างร้านใหม่** แยกต่างหาก ใช้เมื่อเป็นธุรกิจใหม่ที่ข้อมูลไม่เกี่ยวกับร้านเดิม
3. ระบบสลับไปสาขาใหม่ (ว่างเปล่า) ให้เพิ่มสินค้าและเชิญพนักงานของสาขานั้น

### ลบสาขา
1. **ตั้งค่า** → การ์ด **ร้าน (ชื่อร้าน)** → กดถังขยะข้างชื่อสาขา
2. พิมพ์ชื่อสาขาเพื่อยืนยัน แล้วกด **ลบสาขาถาวร**
- สินค้า ล็อต และประวัติของสาขานั้นถูกลบถาวร ร้านต้องเหลืออย่างน้อย 1 สาขา

### เปลี่ยนชื่อร้าน
**ตั้งค่า** → การ์ด **ร้าน** → แก้ **ชื่อร้าน** → **บันทึกชื่อร้าน** (ทุกสาขาเปลี่ยนตาม)

### สลับสาขา
กดชื่อร้านที่เมนูซ้ายหรือแถบบน แล้วเลือกสาขา

### ดูยอดข้ามสาขา
เมื่อสแกนสินค้า หน้าต่างผลการสแกนจะแสดงยอดและรายการล็อต (เลขล็อต วันหมดอายุ จำนวน) ของ SKU เดียวกันในสาขาอื่นด้วย ถ้าสแกน QR ล็อตจะบอกว่าล็อตนั้นเหลือที่แต่ละสาขาเท่าไร ควรใช้ **SKU เดียวกันทุกสาขา** เพื่อให้เทียบกันได้

### โอนของระหว่างสาขา
ทำ **จ่ายออก** ที่สาขาต้นทาง (เหตุผล “ส่งสาขาอื่น”) แล้ว **รับเข้า** ที่สาขาปลายทาง (เหตุผล “โอนจากสาขาอื่น”) โดยอ้างเลขเอกสารกันในหมายเหตุ

## 6. รายงานและการส่งออก

- **รายงาน**: เลือกช่วงวันที่และแท็บ (สต็อกคงเหลือ / เคลื่อนไหว / ใกล้หมดอายุ / ตามหมวด) จากนั้นกด **ส่งออก Excel (CSV)** หรือ **PDF / พิมพ์**
- **สินค้า** และ **ประวัติ** มีปุ่ม **ส่งออก CSV** ของตัวเองด้วย
- แนะนำให้ส่งออกรายงานสต็อกคงเหลือเก็บไว้ทุกสิ้นเดือน

---

## 7. ตั้งค่าร้าน

**ตั้งค่า** → **ตั้งค่าร้าน**
- ชื่อร้าน/สาขา
- แจ้งเตือนใกล้หมดอายุล่วงหน้ากี่วัน (1–730) ตั้งแยกได้ในแต่ละสาขา

## 8. ข้อควรรู้สำหรับเจ้าของร้าน

- ประวัติการเคลื่อนไหว **แก้ไขหรือลบไม่ได้** ถ้าทีมบันทึกผิด ให้ทำรายการชดเชยแล้วเขียนหมายเหตุอ้างเลขเอกสารเดิม
- ถ้า **ลืมรหัสผ่านเจ้าของร้าน** และไม่มีเจ้าของร้านคนอื่น ต้องให้ผู้ดูแลระบบรีเซ็ตจากเซิร์ฟเวอร์ (ดู `doc/HANDOVER.md`) จึงควรมีเจ้าของร้านอย่างน้อย 2 คน หรือเก็บรหัสผ่านไว้ในที่ปลอดภัย
- ขอให้ผู้ดูแลระบบ **สำรองฐานข้อมูล** เป็นประจำ
