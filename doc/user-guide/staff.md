# คู่มือพนักงานคลัง (Staff)

> สิทธิ์ของคุณ: **รับสินค้าเข้า และจ่าย/เบิกสินค้า** ในสาขาที่ได้รับเชิญ
> รายละเอียดเชิงลึกของแต่ละหน้าดูได้ใน [คู่มือฉบับรวม](../USER_GUIDE.md)

| ทำได้ | ทำไม่ได้ |
| --- | --- |
| ดู Dashboard / สินค้า / ประวัติ / แจ้งเตือน | เพิ่ม / แก้ไข / ลบสินค้า |
| **รับสินค้าเข้า** | ปรับยอดสต็อก |
| **จ่าย / เบิกสินค้า** | ดูหน้ารายงาน |
| สแกนบาร์โค้ดดูข้อมูลสินค้า | จัดการผู้ใช้ / ตั้งค่าร้าน |
| พิมพ์ฉลาก QR, ส่งออก CSV สินค้า/ประวัติ | |
| แก้ชื่อตัวเอง / เปลี่ยนรหัสผ่านตัวเอง | |

ถ้านับของแล้วยอดไม่ตรง หรือพบสินค้าที่ยังไม่มีในระบบ ให้แจ้งผู้จัดการหรือเจ้าของร้าน

---

## 1. เข้าใช้งานครั้งแรก

1. เปิดเว็บตามลิงก์ที่ร้านให้มา แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่ได้รับ
2. ไปที่ **เพิ่มเติม** → **ตั้งค่าบัญชี · รหัสผ่าน** → **เปลี่ยนรหัสผ่าน** แล้วตั้งรหัสผ่านของตัวเอง
3. (แนะนำ) เพิ่มเว็บไว้บนหน้าจอโฮมของมือถือ:
   - iPhone: Safari → ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”
   - Android: Chrome → ⋮ → “เพิ่มลงในหน้าจอหลัก”

**เมนูล่างบนมือถือ**: หน้าแรก · สินค้า · **รับเข้า** · **จ่ายออก** · เพิ่มเติม

---

## 2. รับสินค้าเข้า

ใช้เมื่อของมาส่ง รับคืนจากลูกค้า หรือรับโอนจากสาขาอื่น

1. กดแท็บ **รับเข้า** ที่เมนูล่าง
2. **เลือกสินค้า**
   - กดปุ่มสแกน 📷 แล้วเล็งกล้องไปที่บาร์โค้ด หรือ
   - ยิงบาร์โค้ดด้วยเครื่องยิงลงช่องค้นหา หรือ
   - พิมพ์ชื่อ/SKU แล้วเลือกจากรายการ
3. ถ้าสแกนบาร์โค้ด **กล่อง/ลัง** ระบบจะเลือกหน่วยนั้นให้เอง หรือเลือกหน่วยเองได้
4. ใส่ **จำนวนที่รับเข้า** (ใช้ปุ่ม − / + ได้) ถ้าเลือกลัง ระบบจะแสดงว่าเท่ากับกี่ชิ้น
5. ถ้ามีช่อง **เลขล็อต** และ **วันหมดอายุ** ให้กรอกตามข้างกล่อง
6. เลือกหรือพิมพ์ **ผู้จำหน่าย / หมายเหตุ**
7. ดูแถบล่าง `ยอดเดิม → ยอดใหม่` ถ้าถูกต้องแล้วกด **บันทึกรับเข้า**
8. ระบบแสดงเลขเอกสาร `RCV-xxxxx` ถ้ามีของอีกล็อต ให้ทำต่อได้เลย

---

## 3. จ่าย / เบิกสินค้า

ใช้เมื่อขาย เบิกใช้ในร้าน แจกลูกค้า ส่งสาขาอื่น หรือทิ้งของเสีย

1. กดแท็บ **จ่ายออก** ที่เมนูล่าง
2. เลือกสินค้า (สแกน / ยิง / พิมพ์ค้นหา)
3. เลือกหน่วย (ถ้ามี) แล้วใส่ **จำนวนที่จ่ายออก** ซึ่งต้องไม่เกินคงเหลือ
4. ระบบจะบอกว่าจะตัดจากล็อตไหนก่อน (ล็อตที่หมดอายุก่อนจะถูกตัดก่อนเสมอ) **ให้หยิบของจากล็อตนั้นด้วย**
5. เลือกเหตุผล เช่น ขายหน้าร้าน, ขายออนไลน์, เบิกใช้ในร้าน, ส่งสาขาอื่น, ทดลอง/แจกลูกค้า, ของเสีย/หมดอายุ
6. กด **บันทึกจ่ายออก** ระบบแสดงเลขเอกสาร `ISS-xxxxx`

---

## 4. สแกนดูข้อมูลสินค้า

กดไอคอนสแกนที่แถบบน แล้วสแกนสินค้า หน้าต่างผลการสแกนจะแสดง:
- คงเหลือในสาขานี้ (และคิดเป็นกี่กล่อง/ลัง)
- ล็อตและวันหมดอายุ
- ความเคลื่อนไหวล่าสุด
- ปุ่ม **รับเข้า** / **จ่ายออก** เพื่อทำรายการต่อทันที

ถ้าสแกนแล้ว **ไม่พบสินค้า** แปลว่าบาร์โค้ดนี้ยังไม่ได้ลงทะเบียน ให้แจ้งผู้จัดการ

---

## 5. ดูแจ้งเตือนและประวัติ

- 🔔 **แจ้งเตือน**: สินค้าที่ใกล้หมด/หมด และล็อตที่ใกล้หมดอายุ ถ้าของมาแล้วกด **รับเข้า** จากการ์ดได้เลย
- **ประวัติ** (เมนู **เพิ่มเติม** → ประวัติการเคลื่อนไหว): ตรวจรายการที่ตัวเองบันทึก ค้นหาด้วยชื่อสินค้าหรือเลขเอกสารได้

---

## 6. ถ้าบันทึกผิด

ประวัติ **ลบหรือแก้ไขไม่ได้**
- **รับเข้าเกิน**: ทำ **จ่ายออก** จำนวนที่เกิน และเขียนหมายเหตุ “แก้ไขรายการ RCV-xxxxx”
- **จ่ายออกเกิน**: ทำ **รับเข้า** จำนวนที่เกิน และเขียนหมายเหตุ “แก้ไขรายการ ISS-xxxxx”
- **เลือกสินค้าผิด / ล็อตผิด / ไม่แน่ใจ**: แจ้งผู้จัดการให้ปรับยอด

---

## 7. ปัญหาที่พบบ่อย

| ปัญหา | วิธีแก้ |
| --- | --- |
| กล้องไม่เปิด | อนุญาตกล้องในเบราว์เซอร์ ถ้ายังไม่ได้ให้พิมพ์บาร์โค้ดเองในช่องด้านล่างหน้าต่างสแกน แล้วแจ้งผู้ดูแลระบบ |
| “จำนวนคงเหลือไม่พอ” | ตรวจว่าเลือกหน่วยถูก (ชิ้น/กล่อง/ลัง) และยอดในระบบตรงกับของจริงหรือไม่ ถ้าไม่ตรงให้แจ้งผู้จัดการ |
| ไม่เห็นเมนูรับเข้า/จ่ายออก | อาจเลือกสาขาผิด กดชื่อร้านด้านบนเพื่อสลับสาขา |
| ลืมรหัสผ่าน | แจ้งเจ้าของร้านให้ตั้งรหัสผ่านใหม่ |
